# Contributing / Contribuir

Thanks for helping improve QuantumLab! / ¡Gracias por colaborar con QuantumLab!

1. Open an issue describing the bug, scientific concern or proposed enhancement.
2. Fork the repository and create a feature branch.
3. Keep changes focused; avoid changing mathematical algorithms while doing purely UI work.
4. Add a reproducible example or test for each bug fix. For physics changes, cite the analytical identity or established reference used to validate the result.
5. Run `python -m unittest discover -s tests -v` before opening a pull request.
6. Explain what changed and attach screenshots for UI modifications.

Please never commit secrets, proprietary game assets or third-party code without a compatible license.

## Good first contributions

- Improve language accessibility and Unicode font support.
- Add user-editable numerical parameters to the tunneling module.
- Add validation for physically meaningful boundary conditions.
- Improve mobile-like scaling for smaller desktop displays.
- Extend scientific test coverage.
